<h2>一、先确认路由器有没有这个能力</h2>
<p>家用路由器的管理页面通常只有拨号、DHCP、端口转发，没有自定义出口的地方，这类机器做不了。</p>
<p>能刷第三方固件的型号才有戏。刷之前确认硬件版本，同型号不同批次可能不兼容，刷错只能救砖。</p>
<p>企业级或软路由设备天生支持多出口，配置项更全，但需要一点网络基础，不适合完全新手。</p>

<h2>二、地址规划要先做</h2>
<p>先确认光猫是桥接还是路由模式。光猫在路由模式下，路由器拿到的已经是内网地址，很多玩法会受限。</p>
<p>把内网段规划出来，比如 192.168.10.0 段给办公设备，192.168.20.0 段给测试设备，后面按段分流最省事。</p>
<p>地址规划做完再动手。中途改网段会让所有设备重新获取地址，排查问题时也更乱。</p>
<h3>把管理地址记下来</h3>
<p>改配置前把当前管理地址、账号、拨号账号密码写在纸上。断网时你只能靠这些信息回到管理页面。</p>
<h2>三、把住宅出口接进路由器</h2>
<p>如果服务商给的是代理账号，路由器上需要有对应的客户端插件，把地址、端口、凭据填进去。</p>
<p>如果给的是独立线路或专线，接在指定网口上，按服务商给的地址配静态 IP 或拨号。</p>
<p>两条线路同时存在时，先只启用一条并确认能上网，再叠加第二条，出问题才知道是哪条引起的。</p>
<h2>四、策略路由：谁能走这条线</h2>
<p>策略路由决定哪些设备走住宅出口、哪些走本地宽带。按源地址分流最直观，按域名分流更精细但更难维护。</p>
<p>国内站点建议直连，全部走境外出口会让本地服务变慢，视频类站点尤其明显。</p>
<p>规则顺序影响结果，从上往下匹配，第一条命中就生效。写完规则一定检查顺序。</p>

<h2>五、无线与有线侧的差别</h2>
<h3>先把需要固定出口的设备接网线</h3>
<p>有线口和无线口可以绑不同网段，把需要固定出口的设备接网线，手机和平板走另一个 SSID。</p>
<p>访客网络是现成的隔离手段，单独开一个 SSID 绑到测试出口，不影响家里其他设备。</p>
<p>无线侧带宽受信号影响，测速时用网线对比一次，能判断慢是线路问题还是覆盖问题。</p>
<h2>六、稳定性与回退</h2>
<p>给路由器配一个定时重启，跨境链路长时间运行后偶发卡顿，重启能缓解一部分。</p>
<p>准备一条回退路径：拔掉住宅线路，路由器自动回到本地宽带。这个功能在关键时刻能救急。</p>
<p>配置改完导出备份。换设备或刷固件后能直接导入，比照着截图重配快得多。</p>
<h3>断电恢复要测一次</h3>
<p>直接拔电源再上电，看路由器能不能自己恢复代理进程。有些插件开机不自启，断电后就静默失效。</p>
<h2>常见问答</h2>
<h3>路由器上配了代理，为什么手机连 Wi-Fi 还是本地 IP？</h3>
<p>答：多半是规则没覆盖到这个网段，或者设备的地址不在分流范围内。先确认手机拿到的网关和网段，再检查规则。</p>
<h3>刷第三方固件有风险吗？</h3>
<p>答：有。刷错版本可能变砖，需要按型号对应的恢复方式救回。没有把握就先在旧设备上练手。</p>
<h3>能不能只让某台电脑走住宅出口？</h3>
<p>答：可以。按源地址分流，把这一台设备的地址单独写一条规则，其余设备保持默认出口。</p>
<h3>路由器方案比在电脑上装客户端好吗？</h3>
<p>答：设备多、需要统一出口时路由器更省事；只有一台机器要用，客户端方式配置更快也更容易回退。</p>
